Request

curl -s https://api.securityaccelerated.com/v1/domain/lookup \
  -H 'X-API-Key: YOUR_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"domains": ["example.com"],
       "lookups": ["dns", "ssl", "email_security", "risk"]}'

Read the code before you send it anything

The source is published so you can evaluate the service before you trust it with a query. It is source-available with all rights reserved, not open source.

You get what worked
A lookup that fails says why in a per-result errors array. The rest of the response still arrives.
Failures are never cached
Only successful lookups are stored, so an upstream outage is not replayed to you later as an answer.
One path out for lookups
Every HTTP and TLS connection a lookup makes goes through a single SSRF-prevention layer that checks the address at dial time, after DNS resolution.
The release process is in the repo
How a version reaches production, and the approval it waits for, is written down next to the code.
